# EdgeMark

마우스를 화면 왼쪽 끝에 대면 북마크 사이드바가 열리는 Edge 확장 (MV3).
Bookmark Sidebar 에서 꼭 필요한 기능만 남겨 가볍게 다시 만든 것. 외부 라이브러리 없음, 외부 통신은 사용자가 연결한 WebDAV 서버로만.

## 기능
| 기능 | 동작 |
|---|---|
| 자동 열기 | 마우스가 왼쪽 끝(6px 안)에 닿으면 바로 열림. 기본은 창이 최대화일 때만, 창 모드·팝업에서는 왼쪽 끝(24px 안)에 작은 초록 **열기 탭**만 나오고 누르면 열림. 아이콘 클릭으로는 언제든 열고 닫음 |
| 닫기 | 사이드바에서 마우스가 나가면 바로, 바깥 클릭, Esc. 열린 동안 나머지 화면은 반투명하게 덮음 |
| 트리 | 맨 위에 즐겨찾기 모음 내용, 그 아래 '기타 즐겨찾기' 등. 폴더 펼치기/접기, 파비콘 |
| 화면 | 페이지를 확대·축소해도 사이드바는 같은 크기 (감지 폭도 화면 기준). 마우스가 올라간 줄은 초록 테두리, 폴더 펼치기·접기와 사이드바 열고 닫기는 애니메이션 (시간 조절) |
| 열기 | 클릭·Enter → 새 탭(맨 뒤 · 바로 뒤) 또는 지금 탭 / Ctrl·가운데 클릭 → 새 탭(뒤에서) / Shift → 새 탭으로 이동 / 폴더 가운데 클릭 → 안의 북마크 모두 새 탭(10개 넘으면 확인) |
| 검색 | 열리면 검색창에 바로 포커스. 한글 입력 그대로 |
| 키보드 | 검색창 Enter·↓ → 목록, ↑↓ 이동(끝에서 처음으로), Enter 열기, → 펼치기, ← 접기(하위 항목에서는 부모 폴더를 접고 위로), Del 삭제, 글자 → 다시 검색, Esc 검색 지우기 → 닫기 |
| 정리 | 상단 폴더 추가(고른 폴더 안에), 폴더 줄 오른쪽 **+** → 현재 페이지를 그 폴더에, 드래그로 옮기기(폴더 가운데 → 안, 위·아래 가장자리 → 앞·뒤) |
| 삭제 | 상단 휴지통 → 삭제 모드(줄마다 −). 하위 항목이 있는 폴더는 확인. 지운 뒤 5초 동안 되돌리기 |

## 설정 (아이콘 우클릭 → 확장 옵션)
| 설정 | 기본 |
|---|---|
| 항목을 클릭하면 | 새 탭 (맨 뒤, 기본) / 새 탭 (지금 탭 바로 뒤) / 지금 탭에서 열기 |
| 정렬 | 기본 순서(브라우저에 저장된 순서) / 이름 순서(폴더 먼저) |
| 창이 최대화일 때만 열기 | 켜짐 |
| └ 창 모드·팝업에서는 열기 탭만 살짝 보이기 | 켜짐 |
| 한 번에 한 폴더만 펼치기 | 꺼짐 |
| 펼친 폴더 기억하기 | 꺼짐 (끄면 매번 첫 폴더만 펼친 상태로) |
| 글자 크기 · 목록 간격 · 사이드바 너비 | 15px · 40px · 400px (오른쪽 미리보기로 바로 확인) |
| 사이드바 열고 닫는 시간 · 폴더 펼치고 접는 시간 | 100ms · 100ms (0 ~ 300, 0 이면 바로) |

## 동기화 (StayTab · DragOn 과 같은 방식)
| 방식 | 저장 위치 |
|---|---|
| 브라우저 계정 동기화 (기본) | `chrome.storage.sync` 의 `conf` |
| 서버(WebDAV) 동기화 | `chrome.storage.local` 의 `data` + 사용자가 지정한 WebDAV 폴더의 암호화 파일 |

- 서버 파일은 아이디·비밀번호로 암호화 (PBKDF2-SHA256 600k → AES-256-GCM), 파일 이름도 아이디·비밀번호에서 만든 32자리 16진수. TapCode · DragOn · StayTab 과 같은 서버·같은 계정을 써도 파일이 겹치지 않는다 (salt 다름).
- 북마크 자체는 Edge 즐겨찾기 동기화가 맡는다. 펼친 폴더 상태는 이 PC에만 (`chrome.storage.local` 의 `openFolders`).

## 구조
```
manifest.json
background.js     북마크 API 중계(읽기·검색·추가·옮기기·삭제·되돌리기), 탭 열기, 아이콘 클릭, 설정 저장·서버 동기화
sidebar-view.js   사이드바 CSS와 줄 만들기 (content.js 와 설정 화면 미리보기가 같이 씀)
content.js        모든 페이지(최상위 프레임만): 가장자리 감지, 사이드바(closed Shadow DOM)
options.html/js/css   설정 화면
src/              store.js(설정 저장소) sync.js webdav.js crypto.js key.js
```
- 사이드바는 closed Shadow DOM 안에 그려서 페이지 CSS와 섞이지 않고, 사이드바 안에서 누른 키는 페이지 단축키로 넘기지 않는다.
- 트리는 열 때마다 펼친 폴더만 `getChildren` 으로 불러 다시 그린다.
- 사이드바는 서비스 워커를 깨우지 않도록 설정을 저장소에서 직접 읽는다.

## 알려진 제한
- `edge://`, 새 탭, 확장 스토어, PDF 뷰어에서는 동작하지 않는다 (콘텐츠 스크립트가 들어가지 않는 페이지).
- 설치하거나 업데이트한 직후 이미 열려 있던 탭은 새로고침해야 동작한다.
- 페이지 왼쪽 끝을 iframe 이 덮고 있으면 가장자리 감지가 안 된다.
